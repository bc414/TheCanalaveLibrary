# Folder Clusters — Codebase Maintenance Reference

> **Source:** `canalave_library_unified_spec.md` §7.4 (Folder Clusters) and feature specifications throughout §5.
> **Namespace rule:** One namespace per project, regardless of folder organization (§7.4).
> **Clustering criterion:** Do these features share a Layer-1 entity cluster or a Layer-2 interface family?

> **UI columns:** Logic = `@code` behavior (parameters, services, events, state). Structure = component composition and HTML skeleton. Style = Tailwind classes, sprites, visual treatment. These form a dependency chain: Logic → Structure → Style. N/A means the layer genuinely doesn't apply. Columns record **structural facts and settled distinctions only** — build stage/status lives in `status.md`'s grid and the audit files (the per-cell Missing/Blocked status vocabulary was retired 2026-07-27; its "blocked on design tokens" premise died when tokens locked 2026-07-10).
